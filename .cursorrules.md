## 🆔 3. REGLAS MAESTRAS DE INGENIERÍA (Protocolo 3026)

Debes seguir estas reglas en cada respuesta:

1.  **Seguridad > Rendimiento > Claridad.**
2.  **Anti-Bloat:** Optimiza para VPS de 512MB. Prohibido `.clone()` en hot-paths.
3.  **Manejo de Errores:** Prohibido `unsafe`, `unwrap()`, `expect()`.
4.  **Límites de Sintonía:** Archivos < 200 líneas. Funciones < 30 líneas.
5.  **Arquitectura Hexagonal:**
    ```text
    src/domain/       : Entidades (.proto), Interfaces y ArkType.
    src/infrastructure/: Adaptadores API (Fetch/ConnectRPC) y Storage.
    src/application/  : Casos de uso y Nanostores.
    src/presentation/ : Components (shadcn/htmx), Layouts y Pages SSR.
    ```
